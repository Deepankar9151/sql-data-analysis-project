# Instagram User Analytics using SQL

## Project Overview
This project focuses on analyzing Instagram user data using SQL. It aims to understand user engagement, identify active users, analyze likes and comments, and generate insights from social media data.

## Objectives
- Analyze user activity and engagement.
- Identify the most active users.
- Analyze likes, comments, and post performance.
- Find popular hashtags and content trends.
- Generate insights to support data-driven decisions.

## Tools & Technologies
- **Database:** MySQL
- **Language:** SQL
- **Platform:** MySQL Workbench

## Project Files
- `social_media_template.sql` – SQL database template and structure.
- `ig_clone.sql` – SQL queries and database operations for the Instagram clone project.

## Key SQL Concepts
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate functions such as COUNT, SUM, and AVG
- JOINs and subqueries
- Common Table Expressions (CTEs)
- Window functions

## Key Learnings
- Writing SQL queries to analyze social media data.
- Understanding relationships between database tables.
- Extracting meaningful insights from user engagement data.
- Using SQL for data analysis and reporting.

## Conclusion
This project demonstrates the use of SQL to explore social media data and answer business-related questions about user activity and engagement.
